# Workspace Roles and Permissions

## Available roles

DemoDesk has four built-in roles: Owner, Admin, Member, and Guest. The Owner is the single account responsible for billing and ownership transfer. Admins manage settings, members, and security. Members create and manage content. Guests only see the items shared with them.

## Admin vs member

Admins can change workspace settings, manage SSO and SCIM, view the audit log, and invite or remove members. Members can create projects, tasks, and comments, and can invite guests in some configurations. Admin access is powerful, so assign it sparingly and review the admin list quarterly.

## Custom permissions

Enterprise workspaces can create custom roles with granular permissions, such as read-only access to billing or restricted export rights. Custom roles are assigned like built-in roles and are managed from Settings > Roles. Permission changes are recorded in the audit log.
