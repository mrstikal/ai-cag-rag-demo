# Data Export

## Requesting an export

Workspace owners and admins can request a full export from Settings > Data & Privacy > Export. Members can export their own profile data at any time. Exports are queued, and you receive an email when the archive is ready.

If you are acting on behalf of a data subject under the GDPR, include the workspace ID and the scope of the request when you contact support.

## Export formats

Every export is delivered as a ZIP archive containing JSON and CSV files. JSON preserves relationships between records, while CSV is provided for spreadsheet tools. Attachments are included in their original file format.

## Export delivery time

Most exports finish within 30 minutes. Workspaces with large attachment libraries can take up to 24 hours. When the export completes, we send a download link that stays valid for seven days. You can revoke the link early from the same settings page.

## Scope of exported data

An export includes workspace metadata, projects, tasks, comments, files, and the member directory. It does not include other users' private profile data or billing documents, which are available separately. Audit log entries can be exported from the audit log page.
